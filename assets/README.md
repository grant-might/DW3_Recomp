# Drop the launcher art here

Filenames and exact sizes are in **`../docs/ASSETS.md`**. Nothing is required, the launcher
draws its own fallbacks for every slot, so you can add files one at a time.

Expected (design size, author at 2x):

    background.png     1280 x 800
    logo.png           512 x 512  or 640 x 160
    icon.ico           multi-size ICO (16/24/32/48/64/128/256)
    tab_play.png       32 x 32
    tab_memcard.png    32 x 32
    tab_mods.png       32 x 32
    tab_settings.png   32 x 32
    play_banner.png    1150 x 220   (optional)
    header_bar.png     1280 x 72    (optional)
    button_primary.png 260 x 56     (optional)
